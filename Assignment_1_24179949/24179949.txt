5)
Function(s):
-----------
void sort_array(int arr[], int capacity);

Specification:
-------------
This function is used to sort an array of integers in ascending order
using the bubble sort method. The bubble sort method iterates through the
list, compares adjacent elements and swaps them if they are in the
wrong order. This continues until the list is sorted. All unused
elements (-1), if any, remain at the end of the array.

Pseudocode:
----------
FUNCTION sort_array(arr, capacity)
	FOR i in array (capacity - 1)
		FOR j in array (capacity - i - 1)
			IF arr[j] > arr[j+1]
				SWAP arr[j] and arr[j+1]
			END IF
		END FOR
	END FOR

	FOR i in array (capacity)
		FOR j in array (capacity - i - 1)
			IF arr[j] == -1 AND arr[j+1] != -1 
				SWAP arr[j] and arr[j+1]
			END IF
		END FOR
	END FOR
END

-----------
void randomize_array(int arr[], int capacity);

Specification:
-------------
This function is used to randomize an array of integers.
It first collects all the used elements in a temporary array,
shuffles them, and then places them back into the original array
with all unused elements (-1) at the end.

Pseudocode:
----------
FUNCTION randomize_array(arr, capacity)
	used[]
	usedCount = 0

	//collect used elements
	FOR i in array (capacity)
		IF arr[i] != -1
			ADD element to used[]
			INCREMENT usedCount
		END IF
	END FOR

	//shuffle used elements
	FOR i FROM usedCount - 1 TO 1
		j = random integer
		SWAP used[i] AND used[j]
	END FOR

	//put shuffled in array
	FOR i FROM 0 to usedCount
		arr[i] = used[i]
	END FOR

	//fill rest with -1
	FOR i FROM usedCount TO capacity
		arr[i] = -1
	END FOR
END

-----------
double print_median(int arr[], int capacity);

Specification:
-------------
This function iterates through an array using a loop,
extracts the used elements (not -1) into a new array,
sorts that array using bubble sort, and then calculates
the median of the used elements. If there are even number of elements, 
the median is the average of the middle two numbers,  if it odd then 
the median is the middle element. It then prints the array
of used elements and their median. If there are no used
elements, it returns 0.0.

Pseudocode:
----------
FUNCTION print_median(arr, capacity)
	used[]
	count = 0

	FOR i in array (capacity)
		IF arr[i] != -1
			used[count] = arr[i]
			INCREMENT count
		END IF
	END FOR

	//sort elements 
	FOR i in array (capacity - 1)
		FOR j in array (capacity - i - 1)
			IF arr[j] > arr[j+1]
				SWAP arr[j] and arr[j+1]
			END IF
		END FOR
	END FOR

	//calculate median
	IF count % 2 = 1 THEN 
		median = used[count / 2]
		ELSE 
			median = (used[(count / 2) - 1] + used[count / 2]) / 2.0
		END ELSE
	END IF

	RETURN median
END

double print_variance(int arr[], int capacity);

Specification:
-------------
This function takes an array of elements, using only the used elements,
it finds the variance. It find the average, calculates the sum 
of the squared differences of the elements, and finally divides it 
by the total number of used elements.

Pseudocode:
----------
FUNCTION print_variance(arr, capacity)
	sum = 0
	count = 0

	//sum of used elements
	FOR i in array (capacity)
		IF arr[i] != -1
			ADD TO sum 
			INCREMENT usedCount
		END IF
	END FOR

	average = sum / count

	sum_of_difference = 0.0
	FOR i in array (capacity)
		IF arr[i] != -1 THEN 
			difference = arr[i] - average
			ADD difference * difference TO sum_of_difference
		END IF
	END FOR

	//calculate variance
	variance = sum_of_difference / count

	RETURN variance
END

14)
Function(s):
-----------
double print_standard_deviation(int arr[], int capacity);

Specification:
-------------
This function takes an array of elements, using only the used elements,
it finds the standard deviation. It find the average, calculates the 
sum of the squared differences of the elements, and finally divides it 
by the total number of used elements to get variance, then takes the square 
root of the variance to get the standard deviation.

Pseudocode:
----------
FUNCTION  print_standard_deviation(arr, capacity)
	sum = 0
	count = 0

	//sum of used elements
	FOR i in array (capacity)
		IF arr[i] != -1
			ADD TO sum 
			INCREMENT usedCount
		END IF
	END FOR

	average = sum / count

	sum_of_difference = 0.0
	FOR i in array (capacity)
		IF arr[i] != -1 THEN 
			difference = arr[i] - average
			ADD difference * difference TO sum_of_difference
		END IF
	END FOR

	variance = sum_of_difference / count
	//calculate standard deviation
	std_dev = sqrt(variance)

	RETURN std_dev
END
