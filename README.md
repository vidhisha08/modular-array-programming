# modular-array-programming
Overview

This project was completed as an individual programming assignment for the CE4703 Computer Software 3 module at the University of Limerick.

The project focuses on applying modular programming in C to create a menu-driven program for working with integer arrays. The program is divided into separate modules so related functionality could be organised and reused.

Technologies and Concepts

* C programming
* Functions and function prototypes
* Arrays
* Loops and conditional statements
* Random number generation
* Bubble sort
* Statistical calculations
* Menu-driven program design

Program Structure

The program is divided into three main modules.

* array_creations.c

  Functions for creating and managing arrays, including:

    * Generating random integers within a specified range
    * Filling an array using user input
    * Filling an array with random values
    * Clearing an array
    * Marking unused array positions with -1

* array_manipulation.c

  Functions for manipulating and displaying arrays, including:
  
    * Sorting arrays in ascending order using bubble sort
    * Randomising the used elements
    * Printing only used elements
    * Printing all elements
    * Finding the minimum and maximum elements
    * Counting the number of used elements

* array_calculation.c

  Functions for performing statistical calculations on the used elements, including:

    * Average
    * Median
    * Variance
    * Standard deviation
